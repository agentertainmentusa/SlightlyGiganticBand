Contact Form

The Contact form on your homepage sends messages directly to your inbox. You have two options — you can use one or both:

If you don’t set up Formspree below, the form opens the visitor’s email client pre-filled with this address. Also used by the envelope icon in the “Follow” row.

Set this up in 2 minutes: Go to formspree.io → sign up (free — 50 messages/month) → click “New Form” → enter your email → copy the endpoint URL (looks like https://formspree.io/f/xxxxxxxx) → paste it here → click Save Changes. Done. You’ll get an email for every message visitors send.

Login

Account Security

Change the admin password that’s used to sign into this admin panel. After saving, you’ll be signed out and asked to log back in with the new password. The change is instant for everyone — anyone currently logged in elsewhere will also be signed out.

Tips for a strong password
  • At least 10 characters
  • Mix uppercase, lowercase, numbers, and a symbol
  • Don’t reuse a password you use elsewhere
  • Store it in a password manager so the band doesn’t lose access
